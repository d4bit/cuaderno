Conectar con GitHub para guardar

Solo hace falta una vez en este teléfono. La página guarda los cambios cifrados en el repositorio del sitio.

  1. Entra en GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → d4bit/cuaderno.
  3. Permissions → Repository permissions → Contents: Read and write. Caducidad: la máxima.
  4. Copia el token y pégalo aquí.
